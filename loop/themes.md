# テーマキュー(Discovery の対象)

`/art-loop next` はこのファイルを上から走査し、`loop/state/<slug>/state.json` が
存在しない・または未完了のテーマを1つ選んで実行する。

書式: 1行1テーマ。`- [slug] テーマの記述`(slug は `fable5_<slug>.html` になる)。
行頭 `x` で取り下げ(走査対象外)。

## キュー

- [taifu-no-me] 台風の目 — 外縁は荒れ狂い、目の内側は完全な静寂となる巨大な渦 — 本質: 運動と静止の対比 / 手法: 無入力×Stable Fluids(scout 2026-07-19)
- [kotonoha-shigure] 言の葉時雨 — 集音した声は言葉に、環境音はオノマトペになり、墨の活字として画面上部から降って物理演算で積もる。音量=文字サイズ、声色(プロソディ)=書体、感情の高ぶり=朱。着地で墨が和紙ににじみ、古い層ほど圧密して墨痕に風化。満杯になると風が払って白紙に戻る — 本質: 言葉=墨=時間とともに沈殿する無常 / 手法: マイク音声×剛体物理+インスタンス描画(美術: 墨と和紙、挑戦枠=堆積物理)(ユーザー発案 2026-07-19)
