# テーマキュー(Discovery の対象)

`/art-loop next` はこのファイルを上から走査し、`loop/state/<slug>/state.json` が
存在しない・または未完了のテーマを1つ選んで実行する。

書式: 1行1テーマ。`- [slug] テーマの記述`(slug は `fable5_<slug>.html` になる)。
行頭 `x` で取り下げ(走査対象外)。
