# 依頼: WebGL2 リアルタイム映像作品「台風の目」の新規制作

## 1. 作りたいもの

気象衛星の真上からの俯瞰で見る、ひとつの巨大な台風。白い雲の帯(レインバンド)が対数
螺旋状に中心へ巻き込み、外縁は荒れ狂って速く流れ、中心近くには最も濃い雲の壁
(アイウォール)が立つ。そしてその内側だけ、雲が抜けて暗い海面が円くのぞく完全な静寂
—「目」。運動と静止の対比が主題である。

- ファイル名: `fable5_taifu-no-me.html`
- リポジトリ: `dsflon/webgl2`(単一HTML作品集。GitHub Pages で配信)
- **入力: なし**。カメラ・マイク・ポインタを使わず、時間発展だけで駆動する。
  放置して眺める作品(スクリーンセーバー的佇まい)として成立すること。

この様式の本質は「組織化された渦」である。無方向の乱流や煙をそれらしく着色して
近似してはならない。速度場そのものがランキン渦+スパイラルの構造を持ち、雲は
その場に運ばれて螺旋を描くこと(構造は場が作る。テクスチャアニメで描かない)。

## 2. 様式の参照 — 視覚的不変量表(ゲート1通過済み)

参照: 気象衛星ひまわりの台風俯瞰画像(螺旋の雲帯・濃いアイウォール・雲が抜けて海が
のぞく目・外側ほど疎になりちぎれる雲) / ランキン渦(接線速度が半径で増加→アイウォール
半径で最大→内側で急減しほぼ静止する速度分布) / 積乱雲の雲頂の質感(mottle を持つ
盛り上がりの集合、自己遮蔽の影、青みがかった白〜灰)。

## 3. 入力から生き残らせる信号

- 生き残る: **時間のみ**(渦の位相・雲の生成消滅・きらめきのすべてを時間発展が駆動する)
- 様式側で置き換わる: カメラ映像 → 使用しない(完全ジェネラティブ) / 実写の雲 →
  Stable Fluids の密度場が作る雲帯 / 実写の海 → 切れ間からのぞく深い海色の下地
- 被写体は「渦と目」。**縮小して見ても『台風の衛星写真』と読めること**が受入基準である。

## 4. 技術方針(この指定に従うこと)

実装原理は次の技法語彙で固定する: Stable Fluids / curl noise / vorticity confinement /
sdf / oklab / edge darkening / ema / ping-pong。

- **流体コア**: 半解像度 Stable Fluids(semi-Lagrangian 移流+Jacobi 圧力+
  vorticity confinement)。ping-pong FBO、RGBA16F(EXT_color_buffer_float 確認+
  未対応時 RGBA8 フォールバック)。
- **渦の外力(不変量 1/3)**: 中心 C まわりのランキン渦プロファイル
  v_t(r) = v_max · (r/R) (r<R) / v_max · (R/r)^α (r≥R)、R=アイウォール半径。
  接線方向に内向きスパイラル角(10〜20°)を混ぜ、雲が緩やかに中心へ巻き込むようにする。
  目の内側(r < R·0.6)は外力をほぼゼロに減衰(静止の主題)。
- **雲の注入と散逸(不変量 2/6)**: 注入はアイウォール環(r≈R)を最濃に、外側へ複数の
  弧状ソース(cell-hash 的な固定シードで配置、時間シード禁止)。注入強度は curl noise で
  変調し既高密度でテーパ(0.85 で頭打ち)。散逸は中心距離依存: 目の内側で最強(雲を排除)、
  帯域で弱く、画面外縁で再び強く(封じ込め)。すべて sdf(中心距離場)ゲートで実装。
- **雲のレンダリング(不変量 4/5)**: 密度→oklab 補間(深い海 #0b1c2c 系→灰→青白 L≤0.9)。
  密度勾配の擬似法線+光方向(固定・斜め上)2タップ自己遮蔽+curl noise ディテールの
  有限差分でクレバス陰影。周縁ビネットは edge darkening。海面には微細な波のきらめき
  (静的 hash グレイン+ゆっくりの位相、freeze で停止)を弱く。
- **無入力プロファイル**: `<head>` に `<meta name="art-input" content="none">` を宣言する。
  getUserMedia を呼ばない。**使われないカメラ UI・カメラエラー文字列を埋め込まない**
  (検証器を通すための偽装は禁止)。オーバーレイ(#overlay)は実在するエラー経路
  = WebGL2 非対応 / EXT_color_buffer_float 非対応 の表示に使う。
- **?freeze=1(決定的静止フレーム)**: シードは全て固定なので、freeze 時は
  **固定ステップの事前ロール**(dt=1/60 固定で 240 ステップ)を初期化時に実行してから
  時間を停止(dt=0)する。これで「発達した渦の決定的な1フレーム」が毎回同一に出る
  (flicker/alive 検査の前提。目=画面中心は暗い海色だが真っ黒にしない。中心輝度 8/255 超)。
- **?fakesource=1**: 本作は無入力のため**受理して無視**する(パラメタでエラーにしない)。
  合成カメラは存在しない。検証ハーネスは同一 URL 形式で回る。
- **uDebug**: 0=最終 / 1=速度場(方向を色相・速さを明度で) / 2=密度場 raw /
  3=注入・散逸ゲート(sdf の環と目) / 4=雲の陰影標本(法線・自己遮蔽のみ)。

## 8. 技術注意リスト(遵守すること)

1. GLSL ES 3.0 の予約語を変数名に使わない: coherent, sample, filter, precise,
   restrict, readonly, writeonly, subroutine, input, output, common, partition, active
2. 同一テクスチャを read しながら write しない。feedback/拡散/EMA は必ず ping-pong。
3. float テクスチャは EXT_color_buffer_float を確認し、未対応時の代替(RGBA8 パック)を用意。
4. MRT のブレンドは全アタッチメント共通。クリアは clearBufferfv を毎アタッチメント。
5. 方向場は二重角 (cos2θ, sin2θ)。角度の直接 lerp をしない。
6. normalize(ゼロベクトル) は NaN。pow(x,y) は x<0 で未定義(渦プロファイルの (R/r)^α に注意)。
7. ループは const int MAX + break(Jacobi 反復も固定回数)。
8. 頂点シェーダのテクスチャ参照は textureLod。
9. 乱数は pcg系 hash12。シードに時間を混ぜない(ソース配置・mottle・海のグレインすべて)。
10. UNPACK_FLIP_Y_WEBGL は DOM ソースのみ(本作は TypedArray/FBO のみなので既定 false のまま触らない)。
11. gl_PointSize は使用時必ず書く。canvas は preserveDrawingBuffer: true。
12. UV・位置計算は highp。
13. ブラーは縦横分離。readPixels を毎フレーム呼ばない。
14. oklab 変換は正しい行列で(sRGB→linear→LMS→oklab)。補間は oklab で行い sRGB へ戻す。

## 10. 自己批評ルーブリック(スクリーンショット取得後、報告の前に実行)

1. §2 の不変量表の各行を画像と照合し 5 段階で自己採点(存在しなければ1点+理由)。
2. **第一印象**(brief を伏せて「この画像は何に見えるか」)を言語化し、テーマ(台風の
   衛星写真)と一致するか確認する。渦巻き銀河/排水口/ラテアート/ただの煙に見えるなら
   様式不成立(特に「銀河」— 黒地+青白グローに寄ると即座に銀河になる。地は海であること)。
3. 「縮小して見た印象」(渦と目のゲシュタルト)と「等倍で見た印象」(雲の mottle・
   自己遮蔽・アイウォールの質感)を分ける。
4. 最低点の2項目に、§4 の語彙で修正案(数値の増減方向まで)を出す。
5. 全項目4点以上まで最大3周まで自走してよい。採点は甘くしない。
