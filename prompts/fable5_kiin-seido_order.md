# 依頼: WebGL2 リアルタイム映像作品「気韻生動 / Ink Aura Poster」の新規制作

## 1. 作りたいもの

Web カメラが映す**実写の世界をそのまま地として残しながら**、そこに墨の飛沫・にじみ・
かすれた筆致を加える。人物のコアは実写のまま鮮明で、背景は画面の周縁と大きな不規則
パッチから生成りの紙へ溶けていく(背景を全面紙に置換すると「動くバーチャル背景」に
なるため禁止)。身体が動くと、直前の身体が濃紺の水墨として遅れて追い(布の遅延)、
軌道が払いの弧になって残る。止まれば墨は吸われて薄れ、余白が戻る。現代的なデジタル
ペインティング × 水墨・書道のポスターアート。

- ファイル名: `fable5_kiin-seido.html`
- リポジトリ: `dsflon/webgl2`(単一HTML作品集。GitHub Pages で配信)

この様式の本質は「**人物はリアル、周囲は抽象。その境界が筆で破れている**」である。
これを後処理(ぼかし・色調整・オーバーレイ)で近似してはならない(制作規約 失敗モード#1)。

参照した作品像の言語化(添付ポスター):
人物の周囲は墨の飛沫、絵具のにじみ、かすれた筆致で構成され、背景へ向かうほど具象から
抽象へ変わる。円を描く筆の軌跡、乾いた筆のかすれ、勢いのある払い、不規則な余白が、
武術の「気」や身体の軌道を可視化している。濃紺のマントやスカーフは身体より遅れて動き、
直前の動きを想像させる。色はアイボリー・濃紺・墨黒・ブラウン・グレーに抑え、金・銅を
少量のアクセントに用いる。

## 3. 入力映像から生き残らせる信号

- 生き残る: **人物の実写そのもの**(顔・衣服の陰影・素材感)、**実写の背景**(=実際に
  そこにある世界。バーチャル背景に置き換えない)、人物のシルエット、身体の動きの向きと
  勢い、動きの履歴(直前の位置)
- 様式側で置き換わる: 背景の**周縁と不規則パッチ**(紙へ溶ける)、人物の輪郭の縁(墨の
  筆致に破断される)、色域(抑制パレットへグレーディング)
- 被写体(特に人物)が判読できることは受入基準である。**人物のコアは常に不透明**に保つ
  (薄れて幽霊になってはならない)。

## 4. 技術方針(この指定に従うこと)

実装原理は次の技法語彙で固定する: **stable fluids**(墨のにじみ場の移流)、
**curl noise**(乱流ワープ。※出力を単位スケールに正規化して使うこと)、**EMA**(速い/遅い
2本の人物マスク。差が残像の源)、**ping-pong**(場とエージェント状態の全て)、
**SDF**(筆ストロークの線分距離、fakesource の人型)、**stroke splatting**(筆エージェントを
インスタンス矩形で MAX blend 合成)、**edge darkening**(にじみの乾き縁)。

- 検知は **MediaPipe ImageSegmenter のみ**(Pose は使わない。CRAFT §C3)。実カメラ時のみ
  実行時 import。`?fakesource=1` では検知に一切触れず、GLSL の合成室内+動く人型
  (四肢を振る)で全パスを駆動する。
- **筆致は柔らかい場ではなく専用の高解像度レイヤで描く**。流体場が作れるのは柔らかい
  にじみだけであり、載せ筆の弧はハードな縁と毛先の割れを持つ。両者を別レイヤに分け、
  紙 → にじみ(柔) → 筆致(硬) → 人物 → 飛沫 の順で合成する。
- uDebug の割り当て: 0=最終 / 1=マスクと運動場 / 2=墨密度 / 3=速度場 / 4=飛沫と筆致レイヤ /
  5=配色標本。
- モバイル: 推論は長辺 288px の縮小コピーに対して実行し、推論時間に応じて 33〜250ms で
  間引く。GPU デリゲートの出力破綻(全0/全1)が続けば CPU に自動再生成。合成パスの
  ノイズ評価数を抑える(静的な紙は毎フレーム評価せず1度だけテクスチャに焼く)。

## 5. 進め方(フェーズ制・厳守)

- Phase 1: 不変量表の復唱+実装上の懸念点の列挙(コードを書かない)

## 7. 制約条件(リポジトリ規約)

- **単一の自己完結** HTML(WebGL2 / GLSL ES 3.00)。外部依存は MediaPipe tasks-vision の
  CDN とそのモデルのみ(許可リスト内)。
- **カメラ**: `getUserMedia({ facingMode })`、`<video playsinline muted autoplay>`、
  モバイルで前面/背面の切替ボタン。エラー3経路(SECURE CONTEXT / PERMISSION DENIED /
  NO CAMERA)に専用オーバーレイと再試行。
- **品質基準**: 60fps 目標。DPR は 2 で上限。`preserveDrawingBuffer: true`。
  規約ID(`#togglePanel` `#savePng` `#resetLook` `#overlay` `#overlayTitle` `#overlayText`
  `#retryCamera` `#readout` `#panel` `#video`)を踏襲。`prefers-reduced-motion` 対応。
- **検証フック**: `window.__artReady`(最初の本描画フレーム完了で true)、`?freeze=1`
  (時間駆動停止)、`?prewarm=<秒>`(固定 dt の決定的早送り。蓄積が育った絵を撮るため)、
  `?fakesource=1`、`?fakeseg=1`(Y反転検査)、`?fakescale=<f>`(実機スケール検査)。

## 8. 技術注意リスト(既知の地雷)

1. GLSL の**予約語**を変数名にしない(`sample` `filter` `input` `output` `patch` ほか。
   `patch` は本作で実際に踏んだ。沈黙のコンパイル失敗=真っ黒画面になる)。
2. EMA・feedback・場は必ず **ping-pong**(read と write を別テクスチャに)。
3. **curl noise の出力スケールを確認する**。有限差分を 2e で割った生の勾配は大きさが
   ~20 になり、「小さな係数」を掛けたつもりの歪みが 0.2 uv(=200px)になる。
4. マーク配置・グレイン・紙の繊維のシードに `uTime` を混ぜない(freeze でチラつく)。
5. MediaPipe マスクは画像空間(左上原点)。video テクスチャは UNPACK_FLIP_Y=true なので
   **マスク側は `1.0 - y` で反転**して cover-fit を背景と完全一致させる(CRAFT §C1)。
6. マスクの EMA には遅れのハローがあり、これを人物のアルファに直接使うと**カメラの
   背景がそのまま紙の上に描かれる**。アルファは firm 化した現在のマスクから作る。
7. 蓄積レイヤは減衰と注入のバランスを測る(`--longrun`)。注入は高密度域でテーパする。

## 9. 検証環境と手順

- ローカル: `python3 -m http.server 8899` → `http://localhost:8899/fable5_kiin-seido.html`
- **フェイクカメラ**(Playwright `addInitScript` で `getUserMedia` を差し替え)+
  `?fakesource=1` で全パイプラインをオフライン駆動。**スクリーンショット**を1変更ごとに
  撮って自分の目で見る(CRAFT §D1)。デバッグ表示 0〜5 を巡回して場を数値で確認する。
- 決定的検証: `node loop/runner/verify_static.mjs` と
  `node loop/runner/verify_runtime.mjs <url>?fakesource=1&freeze=1 --motion --longrun`
- 実機スケール: `?fakescale=0.5` と `?fakescale=1.9` の両端で final と longrun。
- 向き: `?fakeseg=1&fakesource=1` で合成マスクを実カメラ経路に流し、人物が画面**上**に
  出ることを確認(下に出たら Y 反転が壊れている)。

## 10. 自己批評ルーブリック

各不変量を 1〜5 で自己採点し、4 未満なら原因(構造の欠落か、パラメタか)を書く。加えて:

- **ゲシュタルトテスト**: 先入観なしに「この画像は何に見えるか」を言語化する。
  「墨のポスター」ではなく「煙」「霧」「金属の刷り目」「ぼやけた写真」に見えたら不成立。
- 人物は判読できるか。コアは不透明か。幽霊になっていないか。
- 余白は残っているか。時間が経っても埋まらないか。
- 静止時の絵は成立しているか(動かない被写体でも輪郭の墨が読めるか)。
