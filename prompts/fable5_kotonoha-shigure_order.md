# 依頼: WebGL2 リアルタイム映像作品「言の葉時雨」の新規制作

## 1. 作りたいもの

マイクで集めた音が**墨の活字**になって画面上部から降ってくる作品。声が取れれば言葉
(音声認識は対応環境のみの上乗せ層)、環境音は「ザー」「ゴロゴロ」「ポツ」等の
オノマトペになる。文字は剛体として落下・衝突・回転しながら**物理演算で積もり**、
着地の瞬間に墨が和紙ににじむ。古い層ほど圧密されて濃く沈み、字形を失って墨痕に
風化する。堆積が画面を満たすと**風がひと払い**して白紙に戻り、また最初から始まる。

- ファイル名: `fable5_kotonoha-shigure.html`
- リポジトリ: `dsflon/webgl2`(単一HTML作品集。GitHub Pages で配信)
- **入力: マイク音声のみ**。カメラは使わない。`<meta name="art-input" content="mic">`
  を宣言する(カメラ規約の免除プロファイル。検証器対応済み)。
- マイクが拒否/不在でも作品は死なない: 専用メッセージ+再試行ボタンを出しつつ、
  背後で**デモ時雨**(手続き的なまばらなオノマトペ)が降り続けること。

この様式の本質は「**言葉=墨=時間とともに沈殿する無常**」である。文字を CSS や
DOM で降らせて済ませたり、にじみをただのブラーで置いたりする後処理近似をしては
ならない(制作規約 失敗モード#1)。堆積は本物の物理(衝突・安定静止)であること。

## 2. 様式の参照 — 視覚的不変量表(ゲート1通過済み)

参照: 和紙に活版で刷った墨文字の接写(繊維・漉きムラ・にじみ) / 書道の潤渇
(にじみとかすれ、書いた直後と染み込んだ後は別の状態) / 漫画のオノマトペ・
タイポグラフィ(音の性質が文字の大きさ・太さ・運動に翻訳される) / 落ち葉の
吹き溜まりと風(堆積と一掃のサイクル)。

## 3. 入力から生き残らせる信号

- 生き残る: **マイク音声の RMS(音量)→文字サイズ** / **onset(立ち上がり)→発生
  タイミングと量** / **スペクトル重心・ピッチ・ノイズ性→書体選択と朱の付与** /
  音声認識テキスト(対応環境のみ。言葉が取れれば単語を、取れなければオノマトペを降らす)
- 様式側で置き換わる: カメラ映像→使用しない / 音の波形そのもの→文字記号に置換 /
  消えていく音→墨として紙に沈殿し、堆積・圧密・風化という時間の形で残る
- 受入基準: **音を出すと降り、黙ると止む**因果が体感でわかること。縮小して見ても
  「和紙に墨の文字が積もっている」と読めること。

## 4. 技術方針(この指定に従うこと)

実装原理は次の技法語彙で固定する: グリフアトラス / インスタンス描画 /
剛体物理(衝突応答+スリープ) / AnalyserNode / RMS / ema / ヒステリシス /
oklab / fbm / ping-pong / sdf(高さ場)。

### アーキテクチャの出発点(Phase 2 で対案があれば却下理由付きで比較)

- **音声解析(CPU)**: getUserMedia({audio}) → AnalyserNode(fftSize 2048)。
  毎フレーム RMS / スペクトル重心 / ゼロ交差率を計算し ema で平滑。onset は
  「短期 RMS が長期 ema を係数超え」のヒステリシス付き判定(連射防止のリフラクトリ
  期間つき)。特徴量→(a)発生数 (b)文字サイズ (c)書体クラス (d)朱確率 (e)オノマトペ種別。
- **語の供給**: (1)Web Speech API(webkitSpeechRecognition)を feature-detect し、
  取れた語を優先キューへ(**ネットワーク必須・Chrome系限定**の上乗せ層。失敗・
  非対応・オフラインは沈黙にフォールバックし、エラーにしない)。(2)オノマトペ辞書
  (ザー/ゴー/ポツ/カタ/コト/ゴロゴロ/サラサラ/シーン… 15〜25語)から音特徴量で選択。
- **グリフアトラス(canvas2D→テクスチャ)**: 文字×書体クラスごとに 2D canvas で
  描画し 1〜2 枚のアトラスに詰める(LRU で有界、上限 256 グリフ程度)。書体クラスは
  システムフォントスタック+**合成差**(太字合成・斜体スキュー・サイズ比・字間)で
  最低 3 クラス(明朝系=細く静か / ゴシック太=強い音 / 丸み=柔らかい音)。
  ※検証環境の日本語フォントは Unifont 1 種のみ → 書体差はスタックが解決しない
  環境でも**合成差で見分けられる**こと(実機ではフォント族の差も乗る)。
- **剛体物理(CPU、決定的)**: 文字=回転つき矩形ボディ。重力+空気抵抗、
  地面/堆積との衝突は**カラム高さ場**(画面幅を~192 カラムに離散化した 1D sdf 相当)
  に対して行い、ボディ同士は空中の近傍のみ簡易衝突。着地して速度が閾値以下に
  静定したら**蓄積レイヤへ転写してボディを除去**し、そのフットプリントで高さ場を
  更新する(アクティブボディ上限 ~200、総物量は蓄積レイヤに逃がして有界化)。
  固定タイムステップ(1/60 の substep)+シードは pcg 系 hash12(**時間をシードに
  混ぜない**)で freeze の決定性を保つ。
- **蓄積レイヤ(ping-pong RGBA8、紙解像度=DPR≤2 の全画面)**: R=墨密度 /
  G=定着年齢 / B=朱量。転写時は回転つきグリフをスタンプ(instanced quad を
  レイヤFBOへ描画)。毎ステップ弱い異方性拡散(fbm 繊維方向に沿う 2 タップ)を
  着地直後の若い墨ほど強くかけ「にじみ→定着」を作る。埋没深さ(高さ場との差)で
  コントラスト低下+濃度沈降=風化。**減衰なし保持**が基本、払いフェーズのみフェード。
- **払い(リセット)**: 高さ場の平均/最大が閾値到達→風フェーズ: アクティブボディへ
  横風インパルス、蓄積レイヤは横方向スミア+フェードで数秒かけ白紙へ、高さ場ゼロ。
- **合成(最終パス)**: 紙地(fbm 繊維+漉きムラ+周縁の軽い焼け)× 蓄積レイヤ
  (oklab 無彩補間+朱)× 落下中ボディ(インスタンス描画、シャープ)+無音時の塵。
- **?fakesource=1(合成入力)**: WebAudio・マイクを一切使わず、**決定的スクリプト
  の音イベント列**(固定シーケンス: onset 時刻・音量・重心・語)で発生系を駆動する。
  時間軸検証(--motion)の前提として、fakesource では**常に一定間隔で文字が降り
  続ける**こと(動く要素の保証)。`?freeze=1` 併用時は固定 dt で N ステップ事前
  ロールして決定的な「積もった1フレーム」を出し dt=0(シードは全て固定)。
- **uDebug**: 0=最終 / 1=物理デバッグ(ボディ矩形ワイヤ+高さ場の線) /
  2=蓄積レイヤ raw(R=墨/G=年齢/B=朱) / 3=音特徴量メータ(RMS・重心・onset・
  選択中の書体/語。fakesource ではスクリプト値) / 4=標本(紙地見本+墨の oklab
  ランプ+にじみ前後のグリフ標本+朱)。

### 作品固有の注意

- 蓄積レイヤは feedback なので **ping-pong 必須**、毎ステップ clamp(CRAFT §A5)。
- readPixels を毎フレーム呼ばない: 高さ場は CPU 側のカラム配列で管理し、GPU への
  readback をしない(転写は CPU が位置を知っているので不要)。
- canvas2D→テクスチャは UNPACK_FLIP_Y_WEBGL(DOM ソース)の向きに注意(§8-10)。
- 文字が読める活字であること: アトラス解像度はグリフあたり 64〜96px を確保し、
  拡大は 2 倍まで(それ以上は発生サイズ側で制御)。
- 無音・マイク拒否・認識不可の**三重フォールバック**が全て「静かな作品」として
  成立すること(空白画面・エラー画面で放置しない)。

## 8. 技術注意リスト(遵守すること)

1. GLSL ES 3.0 の予約語を変数名に使わない: coherent, sample, filter, precise,
   restrict, readonly, writeonly, subroutine, input, output, common, partition, active
2. 同一テクスチャを read しながら write しない。蓄積レイヤは必ず ping-pong。
3. float テクスチャは EXT_color_buffer_float を確認(本作の蓄積は RGBA8 で足りる
   設計を優先し、使う場合のみフォールバックを用意)。
4. MRT 不使用を推奨(単純な単一アタッチメント構成で足りる)。
5. 回転は行列/複素数で。角度の直接 lerp をしない。
6. normalize(ゼロベクトル) は NaN。pow(x,y) は x<0 で未定義。
7. ループは const int MAX + break。
8. 頂点シェーダのテクスチャ参照は textureLod。
9. 乱数は pcg 系 hash12。シードに時間を混ぜない(イベント連番・セル座標を使う)。
10. UNPACK_FLIP_Y_WEBGL は DOM ソース(canvas2D アトラス)のみ。TypedArray は
    シェーダ側で向きを合わせる。
11. gl_PointSize は使用時必ず書く。canvas は preserveDrawingBuffer: true。
12. UV・位置計算は highp。
13. ブラーは縦横分離・有界回数。readPixels を毎フレーム呼ばない(高さ場は CPU 管理)。
14. AudioContext は ユーザー操作後 resume(自動再生ポリシー)。マイク不許可でも
    例外を握りつぶさず専用経路へ。
15. 物理は固定 substep+上限付き反復。スリープ判定で永久振動を殺す。
    NaN ガード(速度・位置の isFinite チェック)を入れ、壊れたボディは除去する。

## 9. 検証環境

- 検証ハーネスは `loop/runner/`(verify_runtime.mjs / testscene.mjs)を使う。
  ハーネスのフェイクカメラ機構は本作では発火しない(カメラ不使用)が、URL 形式は
  共通: `?fakesource=1&freeze=1`。ローカルサーバは python3 -m http.server 8888。
- スクリーンショットは (a) 最終合成(非 freeze で 8〜15 秒 warm=積もった状態)
  (b) uDebug 1(物理)・2(蓄積)・3(音メータ)・4(標本) (c) freeze の決定的
  フレーム の計6枚以上。pageerror が出ていないことを毎回確認する。
- **蓄積系なので `verify_runtime --longrun` 必須**(whiteout/発散なし。CRAFT §A5)。
  墨は「暗くなる」方向の蓄積なので黒つぶれ側の発散(mean が下がり続けて紙が
  見えなくなる)も自分で確認し報告すること(検証器は white 側しか見ない)。
- **時間軸の不変量があるので `--motion` 必須**。中心 96px サンプルで拾えるよう、
  fakesource は画面中央にも文字が落ちるイベント列にすること。
- 検証環境の日本語フォントは Unifont 1 種のみ。**書体クラスの差は合成差
  (太字・スキュー・サイズ比)で sandbox でも見分けられる**こと。実機フォント
  (明朝/ゴシック/丸ゴ)での見えは「未検証」と明記する。
- マイク実入力・Web Speech API(ネットワーク必須)は sandbox で検証できない。
  「未検証」と明記し、確認すべき点(許可ダイアログ後の動作・認識語の降下)を列挙する。
