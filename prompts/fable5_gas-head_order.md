# 依頼: WebGL2 リアルタイム映像作品「Gas Head Cam」の新規制作

## 1. 作りたいもの

Webカメラの人物を検知し、**スーツ(身体)は実写のまま残しつつ、頭部だけを立ち上る大量の
粒状・排気ガス的な煙に置き換える**「ガスヘッド」作品。参照画像 `refs/ref1_gashead.jpg`
(黒背景・スーツは鮮明・頭部が白青い煙となってもくもく立ち上る)の忠実な再現を目指す。
`refs/ref2_wisps.jpg` は煙量が少ないときの副次的な見え方(顔を薄煙が横切る)の参考。

- ファイル名: `fable5_gas-head.html`
- リポジトリ: `dsflon/webgl2`(単一HTML作品集。GitHub Pages で配信)

この様式の本質は「**身体は実写・頭部だけが実際に立ち上る体積煙**」。全身を煙にしたり、
頭に半透明の煙画像を重ねただけにしてはならない(制作規約 失敗モード#1)。

## 2. 様式の参照 — 視覚的不変量表(ゲート1通過済み)

参照(brief.references):
1. `refs/ref1_gashead.jpg` — 黒背景。ティール/白の大量の煙が頭部位置から巨大に立ち上る
   (カリフラワー状の乱流・膨らむ体積感)。首から下(肩・襟・ネクタイ)は実写のまま鮮明。
   煙は首元ほど濃く白青、上へ広がり薄れる。全面に細かい粒状感。
2. `refs/ref2_wisps.jpg` — 座った人物の周りに薄い煙がたなびき顔を部分的に覆う軽い状態。
3. 排気ガス的な粒状の煙 — 均一フォグでなく粒が凝集したディテール。縁がちぎれてほつれる。

## 3. 入力映像から生き残らせる信号

- 生き残る: 身体(マスク内は実写)/ 頭部の位置・大きさ(噴出源と置換範囲)/ 身体の動き(煙の外乱)
- 置き換わる: 顔・頭部(立ち上る体積煙)/ 背景(黒+微ヘイズ)/ 頭部境界(実写→煙の遷移)
- 参照1が主目標(頭部が完全に煙)。参照2は煙量を下げたときの副次状態として成立すればよい。

## 4. 技術方針(この指定に従うこと)

### 4.1 人物・頭部検知(MediaPipe。外部依存は ML 例外として許可)
- `@mediapipe/tasks-vision`(CDN: jsdelivr、参照実装 `overflowing_aura_4taigyo_v2.html` と同系)を
  ESM import。**ImageSegmenter**(selfie_segmenter)で人物マスク、**PoseLandmarker**
  (pose_landmarker_lite)で頭部(鼻・目・耳)と肩のランドマークを取得。
- 頭部楕円 = 鼻/目/耳の重心を中心、両肩幅と鼻〜肩距離から半径を算出。中心・半径は EMA 平滑化。
- 噴出源 = 頭部楕円の下部(首元)。座標は EMA。
- モデルは CDN 非同期ロードし進捗を表示(FOLDING/LOADING 相当)。ロード失敗は専用オーバーレイ+
  リトライ、黒+微ヘイズで継続する選択肢も。**検知の推論はレンダリングと分離**(latest-wins・
  rAF 内で await しない)。描画は 60fps を維持し、検知結果は EMA でフレーム補間。

### 4.2 煙(流体)
- `fable5_smoke-portrait.html` の Stable Fluids エンジンを流用してよい(半解像度 ≤512、
  semi-Lagrangian 移流、Jacobi 圧力反復、vorticity confinement)。
- 密度注入は**頭部楕円の下部(首元)から**。buoyancy で上昇、curl noise で乱流化。首元濃く上へ薄く。
- 粒状化: 密度に多オクターブ noise(fbm)を乗算。縁はノイズディザで破断させ、ちぎれた縁に。

### 4.3 合成・配色
- 身体: マスク内かつ頭部楕円外はカメラ映像をほぼ実写で(軽い split-tone のティール寄せ)。
- 頭部楕円内: 実写→煙に smoothstep でクロスフェード(境界がソフト)。
- 背景(マスク外): 黒+わずかな粒状ヘイズ。
- 煙色: 密度→白青ランプ(下部濃色→上部淡色)。合成後に強コントラスト曲線で黒から立てる。
- 全面に cell-hash 静的フィルムグレイン。

### 4.4 検証スイッチ(必須)
- **?fakesource=1**: MediaPipe を使わず、合成シーンを駆動。中央に頭部楕円+肩(人物マスク)を
  描き、頭部がゆっくり動く。これで検知以外の全パイプライン(煙・粒状・配色・追従)を
  オフライン検証できること。
- **?freeze=1**: 時間駆動(流体・buoyancy・curl・グレインのアニメ・fakesource の動き・
  検知 EMA)を全て停止し、決定的な静止フレームを出す。
- **window.__artReady**: 最初の本描画フレームで true。
- **uDebug セレクタ**: 0=最終 1=人物マスク 2=頭部楕円/噴出源 3=煙密度 4=速度場。

  (**本作の例外: `@mediapipe/tasks-vision` の CDN import と、それが取得するモデル**)。

- ファイル冒頭 HTML コメントに: 作品概要 / 実行方法 / 様式解析(不変量) / パイプライン図 /

- 実装前に `fable5_smoke-portrait.html` を読み、パネル構造(固定✕+.panel-body)・カメラ・
  エラー表示・PNG保存の規約を踏襲。state 集約、スライダーは配列生成、DEFAULTS+リセット、

### 検証フック(機械検証が依存。必須)

- デスクトップ60/モバイル30fps 目標(DPR上限2、流体は解像度上限)。検知は webgpu/wasm 問わず
  非同期で描画をブロックしない。リサイズ・カメラ切替・タブ復帰で壊れない。

## 8. 技術注意リスト(遵守)
1. GLSL 予約語を変数名に使わない(coherent sample filter precise restrict readonly writeonly …)。
2. 流体/feedback/EMA は必ず ping-pong(同一テクスチャ read&write 禁止)。
3. float テクスチャは EXT_color_buffer_float 確認+未対応フォールバック。
4. 速度クランプと密度減衰で NaN 防止。normalize(0) は微小値を足す。pow(x,y) は x<0 未定義。
5. Jacobi は const int MAX+break。乱数は pcg hash12。グレイン/粒のシードに時間を混ぜない。
6. MediaPipe 推論を rAF 内で await しない(latest-wins)。検知座標はミラーと同一 UV 系に載せる。
7. UNPACK_FLIP_Y_WEBGL は DOM ソースのみ。canvas は preserveDrawingBuffer: true。
8. タブ非表示で検知ループ停止、visibilitychange で復帰。ブラーは縦横分離。readPixels 毎フレーム禁止。

## 9. 検証環境
- フェイクカメラ+スクリーンショットは `loop/runner/`(testscene.mjs / verify_runtime.mjs)。実行時検証 URL:
  `?fakesource=1&freeze=1`。フリッカ検査はこの状態。時間軸不変量(#2,#5)があるので `--motion` も付ける。
