# 発注書 — opus5_hana.html（「花」/ 歌に咲く花・音で進むライフサイクル）

## 1. 作りたいもの（ユーザー確定要件）

ユーザーが**ギターで弾き語りで「花」という歌を歌う**。集音した音声に合わせて花を印象的に
表現する。音量・声色・動きに合わせて花の動き・表現・色をインタラクティブに演出する。
**花びらがただ舞うだけでなく、芽が出て花が咲くまでのドラマティックな過程**を音に合わせて
表現する。

- ファイル名: `opus5_hana.html`
- リポジトリ: `dsflon/webgl2`（単一HTML作品集。GitHub Pages で配信）

参照する既存作品（この2つの良い部分を合成する）:
- `fable5_flower-being.html` — **花・花びらの表現**（離散スプライトの花/花びら、極彩色、
  発光、GPU パーティクル、instanced quad、動き=突風）
- `opus5_kiin-seido.html` — **人物周辺への表現方法**（実写の地を残す・抽象度場=周縁+fbm
  パッチ−人物近傍・人物のコアは実写・検知とモバイル recipe・検証フック一式）

## 2. 視覚的不変量（優先度 1>2>3>4>5>6）

| # | 不変量 | 担当軸 | 実装原理 | 外した場合 |
|---|---|---|---|---|
| 1 | 音が進めるライフサイクル。種→芽→茎→蕾→開花→満開→散華。根を持つ株として育つ | 時間 | 株は固定プールの GPU 状態機械。stage∈[0,4.6] を **音だけ**が進める（持続音=伸長 / アタック=開花 / 無音=萎れ） | 「舞う花びら」だけになり、依頼の核（ドラマ）が消える |
| 2 | 人物は実写・周囲が花園。花は人物の周縁帯と画面下から芽吹き外へ咲く | 空間 | 抽象度場 =(周縁 + fbm パッチ − 人物近傍)。近傍項は curl ワープ+2スケールの fbm で破断（暗い地では滑らかな保護域が**スポットライト状の人型ハロー**になる） | 「動くバーチャル背景」または切り抜きシールに見える |
| 3 | 音の要素が別々の視覚量に写る | 知覚 | 音量=開き・発光・舞い上がり / 重心=**色相** / 音高=**茎の高さ** / onset=一斉開花と花びら射出 / ZCR=綿毛 / ビブラート=揺れ | 「なんとなく反応する」だけで、歌っている本人が対応を読めない |
| 4 | 花は離散した個体（丸いボケ玉にしない） | 質感 | 幅の広い花弁+外側だけ噛む暗いスリット+喉が暗く先が明るい階調+小さな発光花芯。茎・葉・蕾・穂。散る花びらは涙型で tumble | 星・スパークルに見える（CRAFT §B1） |
| 5 | 有界性 | 時間 | 株と花びらは固定プール（構造的に有界）。前乗算アルファ合成＋明部のみブルーム＋肩付きトーンマップ。無音が続けば散って余白が戻る | 数十秒で画面が埋まる／白飛び（CRAFT §A5） |
| 6 | 頑健性・モバイル | 頑健 | マイク拒否/カメラ拒否/MediaPipe 未ロードでも自走する「デモ呼吸」で成立。検知は ImageSegmenter のみ・288px 縮小・33〜250ms 適応間引き・GPU 破綻時 CPU 切替 | 実機で無反応・落ちる |

## 3. 音 → 視覚のマッピング（実装値）

| 音の量 | 取り方 | 視覚 |
|---|---|---|
| 音量（速い RMS） | AnalyserNode fft2048 / EMA 50ms | 花の開き、花芯の発光、花びらの舞い上がり |
| 持続音（遅い RMS） | EMA 1.8s | **成長の燃料**（芽吹き・茎の伸長・蕾） |
| 声色（スペクトル重心） | 重み付き平均 / EMA 0.2s | **色相**（低=深紅・紅薔薇 / 中=紅梅・桃・金 / 高=白・淡青・菫） |
| 音高（支配周波数） | 70–1200Hz のピークビン → log 正規化 | **茎の高さ**（高い声=高く伸びる） |
| アタック（onset） | 速い RMS が遅い RMS を超える（ヒステリシス+リフラクトリ 0.13s） | 蕾がほどける／一斉開花／花びらの射出 |
| 息のノイズ（ZCR） | ゼロ交差率 | 綿毛（種）が舞い上がる |
| ビブラート | 速い音高と遅い音高の差 | 茎と花の揺れ |
| 楽章（arc） | 上記の蓄積（無音で減衰） | 色相バイアス・散華の勢い（曲に始まりと終わりが出る） |

## 4. 技術方針

- 単一自己完結 HTML（WebGL2 / GLSL ES 3.00）。外部依存は MediaPipe tasks-vision の CDN と
  そのモデルのみ。音声は WebAudio の AnalyserNode のみ（音声はどこにも送らない）。
- 株は 1テクセル1株の **MRT 2枚 ping-pong**。A=(根x,根y,stage/5,wilt) B=(seed,色相,高さ/2,向き)。
  休眠は wilt≥0.999（RGBA8 フォールバックでも成立するセンチネル）。発芽は**毎秒レート**を
  プールで割った確率（フレームレートや prewarm 刻みに density が依存しない）。
- 根の配置は棄却サンプリング（人物の soft 縁帯 or 画面下の fbm クランプ）。**外れたら発芽しない**
  （全画面ばら撒きのフォールバックは禁止 — CRAFT §B3）。伸びる向きは −grad(aura)（体の外へ）と
  上方向の合成。
- 花びらは自由粒子の MRT 2枚 ping-pong。**開花した株の花冠からのみ**発生（最初の開花まで
  花びらは存在しない）。各粒が自分の加速度を積分（重力＋音量による上昇＋運動場の突風＋
  curl ノイズ＋tumble）— 流体場での移流にしない（CRAFT §A4）。
- 描画は **前乗算アルファの重ね合わせ**（加算ではない）。暗い緑の茎を実写の上に載せるため。
  発光は rgb>1.0 で書き、明部しきい値（0.80–1.60）でブルームに拾う。
- 合成順: 実写の地（抽象度場で夜の花園へ）→ 花レイヤ → 人物のコアを 50% 手前へ戻す
  → ブルーム加算 → 肩付きトーンマップ → 粒子・周辺減光。
- uDebug: 0=最終 / 1=マスクと運動 / 2=音の特徴量メータ（下から rms・sus・重心・ZCR・音高・楽章）
  / 3=芽吹き場 / 4=花・花びら層 / 5=配色標本。

## 5. 検証（実施済み）

- `node loop/runner/verify_static.mjs opus5_hana.html` → GA タグ（全作品共通の既知検出）以外 0。
- `verify_runtime <url>?fakesource=1&freeze=1 --motion --longrun` → **11/11 pass**
  （flicker 0.000 / longrun 48.9→59.7 / motion 7.357）。
- `?fakescale=0.5` と `?fakescale=1.9` の longrun → 両端 pass。
- `?fakeseg=1` → 既知向きの合成マスクが画面**上**に出る（Y反転 OK）。
- `?fakesource=1&prewarm=8..14` のスクショで芽→蕾→開花→散華とゲシュタルトを目視。
