# 作品一覧ページ(ギャラリー) — デザイン & 実装計画

> 対象: https://dsflon.github.io/webgl2/ (現状 index.html が無く、テキストリンクは README のみ)
> 本書は**計画のみ**。実装は本書の承認後に別 PR で行う。

---

## 0. ゴール

- Pages のルートに `index.html` を置き、**全29作品**をカード UI で一覧できる
  「作品集の顔」を作る。
- カード = サムネイル / 作品タイトル / 実装日 / 1〜2行の概要 / 技法タグ。
- レスポンシブ(モバイル1列 → タブレット2列 → デスクトップ3〜4列)。
- リポジトリ規約に合わせ **ビルド工程なし・外部ライブラリなし・自己完結**。

## 1. 現状調査(実測)

- ルート直下の HTML 作品: **29 本**。`index.html` は存在しない。
- 実装日は `git log --follow --reverse` の初回コミット日で全作品分取得できる
  (2026-06-13 dogra-magra 〜 2026-07-17 mosaic)。
- サムネイル自動撮影に使える検証フック(`?fakesource=1`/`?fakedepth=1`+`__artReady`)を
  持つのは 7 作品。残り 22 作品は fakeCameraInit(getUserMedia モック)注入+作品ごとの
  起動手順(スタートボタン等)の記録が必要。
- 既存の Playwright 撮影基盤(`loop/runner/`)がそのまま流用できる。

## 2. デザインコンセプト — 「黒の展示室」

作品の大半は「黒地に発光する像」(煙・花・金モザイク・オーラ)。ギャラリーは
**暗い展示室**に徹し、カード(サムネイル)だけが光る。UI は作品内パネルと同じ
モノスペース+小さめの英字見出しの語彙を引き継ぎ、コレクション全体の統一感を出す。

### 2.3 カードの解剖

- **サムネイル**: 16:10 固定(`aspect-ratio: 16/10` で CLS ゼロ)。`loading="lazy"`
  `decoding="async"`。
- **日付**: mono・小・`--muted`。初回コミット日(§1)。直近14日以内は `NEW` バッジ
  (アクセント色、クライアント側で日付比較)。
- **タイトル**: 15〜16px セミボールド。日本語主体(例「黄金地モザイク」)+
  mono の slug サブライン(`fable5_mosaic`)。
- **概要**: 12.5px・2行 `-webkit-line-clamp`。「何が起きる作品か」を1〜2文。
- **タグ**: 小さな mono チップ。語彙は固定セット
  `WebGL2 / MediaPipe / Depth / Fluid / Particles / Voronoi / Audio / ASCII` 等から
  1〜3個。シリーズ(FABLE5 / SUIBOKUGA / AURA / EARLY 等)も同形のチップで表す。
- **ホバー**(ポインタ環境のみ): カード `translateY(-4px)`+枠がアクセント色に、
  サムネ `scale(1.03)`(300ms)。`prefers-reduced-motion` では無効。
- **カード全体が1つのリンク**(`<a>` ブロック)。フォーカスリングはアクセント色2px。

### 2.4 レスポンシブ

- グリッド: `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); gap: 20px;`
  コンテナ `max-width: 1240px`。
  → 実効: **〜599px = 1列 / 600〜919px = 2列 / 920〜1239px = 3列 / 1240px〜 = 4列**
  (auto-fill なので端末幅に自然追従。メディアクエリは hero の文字サイズ調整のみ)。
- モバイル: hero を詰める(件数・注記を1行に)。タップターゲット=カード全面。
- サムネは1解像度(800×500)で全ブレークポイント共用(容量重視。§4)。

### 2.5 アクセシビリティ・品質

- `alt` = 「<タイトル> のスクリーンショット」。コントラスト AA(muted テキストは
  12.5px 以上で 4.5:1 を満たす値に調整)。
- キーボード: カードは通常の `<a>`(Tab 順=DOM 順=新しい順)。
- `<noscript>`: JS 無効時は素のリンクリストを表示(§3 のデータ駆動の代替)。
- OGP(`og:title/description/image` — 代表サムネ1枚)と favicon(シンプルな
  テッセラ1枚の SVG)を同梱。

## 3. 情報設計 — `works.json`(単一の情報源)

作品メタデータは手書きの静的マニフェスト **`works.json`** に集約し、`index.html` が
fetch して描画する(ビルド工程なしでデータと見た目を分離。作品追加=JSON に1エントリ+
サムネ1枚)。

```json
{
  "slug": "fable5_mosaic",
  "file": "fable5_mosaic.html",
  "title": "黄金地モザイク",
  "date": "2026-07-17",
  "desc": "人物が金と色ガラスのテッセラのタイル画になる。目地とベベルを持つ voronoi 分割、金地は動きで反射がきらめく。",
  "tags": ["WebGL2", "MediaPipe", "Voronoi"],
  "series": "FABLE5",
  "thumb": "thumbs/fable5_mosaic.jpg"
}
```

- 並び順: `date` 降順(同日内は配列順)。
- 概要文(29本)は実装 PR で執筆する(各作品のヘッダコメント1節から要約)。
- v1 はフィルタなしの単一グリッド。シリーズ絞り込みチップは P3(§5)。

## 4. サムネイル生成パイプライン

`tools/thumbs.mjs`(新規。`loop/runner/` の playwright-core と testscene.mjs を流用)で
**再現可能に自動生成**する。出力: `thumbs/<slug>.jpg`(800×500・JPEG q≈82・
目標 ≤120KB/枚・計 ≤3.5MB)。

- 共通: viewport 1000×625・DPR1 → 800×500 へ縮小。fakeCameraInit を addInitScript。
  UI パネルは閉じる(`#closePanel` / HIDE UI 相当のセレクタをレシピに記録)。
- **レシピ表**(`tools/thumbs.recipes.json`): 作品ごとに
  `{ query, warmMs, clickSelectors, note }` を記録。
  - フックあり7作品: `?fakesource=1`(papercraft 系は `?fakedepth=1`)+ warm 8〜15s。
  - フックなし22作品: fakeCameraInit 注入で自動再生されるものはそのまま、
    スタートボタン式(例 overflowing_aura 系 `#startBtn`)は clickSelectors で押下。
    **P1 で全29作品の起動手順を実地調査してレシピ化**する(本計画の主要作業)。
  - 音声入力作品(ds_voice)等、自動撮影が困難なものは `thumbs/manual/` の手動画像が
    あればそれを優先(スクリプトが上書きしない)。
- サムネは**コミットする**(Pages はビルドなしのため)。再生成は
  `node tools/thumbs.mjs [slug…]` で差分だけ。

## 5. 実装フェーズ(それぞれ受入基準つき。実装は承認後)

### P1 — データとサムネイル(裏方)
1. `tools/thumbs.mjs` + `tools/thumbs.recipes.json`(29作品の起動レシピ実地調査)
2. `works.json`(29エントリ: タイトル・日付=git 初回コミット日・概要文・タグ)
3. サムネ29枚生成・コミット
- **受入**: 全29枚が黒画面/オーバーレイ被りでないことを目視一覧(コンタクトシート
  を1枚組んで確認)。works.json は簡易スキーマ(必須キー・日付形式)を通す。

### P2 — index.html(見た目)
1. §2 のトークン・レイアウトで `index.html` を実装(自己完結・vanilla JS・
   works.json を fetch して描画・noscript フォールバック)
2. レスポンシブ確認: 360 / 768 / 1280 / 1600px の Playwright スクショ4枚
3. a11y: alt・フォーカスリング・reduced-motion・コントラスト
- **受入**: 4幅のスクショで崩れなし(1/2/3/4列)。Lighthouse 相当の手動チェック
  (CLS=0、遅延読み込み、total ≤ 4MB)。既存作品ページへの変更ゼロ。

### P3 — 仕上げ(任意・小)
1. OGP + favicon(SVG)
2. シリーズ絞り込みチップ(FABLE5 / SUIBOKUGA / AURA / ALL)
3. ホバーで短尺ループ動画(webm 2〜3s)に差し替える演出 — **ストレッチ**。
   容量と撮影コストが大きいので効果を P2 の反応を見て判断。
- **受入**: OGP が X のカードプレビューに出る。チップ絞り込みが JS 無効時も
  破綻しない(単に全件表示)。

## 6. リスクと対処

| リスク | 対処 |
|---|---|
| フックなし22作品の起動手順が多様(ボタン・音声・クリック待ち) | P1 のレシピ実地調査で吸収。困難なものは手動サムネ(`thumbs/manual/`)へ退避 |
| サムネ容量で Pages が重くなる | 800×500 JPEG q82・≤120KB/枚・lazy loading。合計 ~3.5MB 上限 |
| works.json 手書きの日付・記述ミス | 日付は git から機械抽出したものを貼る。簡易スキーマ検証を P1 に含める |
| README のリンク一覧との二重管理 | README は「リポジトリの目次」として残置。**作品追加手順**(works.json+サムネ+README 1行)を index.html 冒頭コメントに明記 |
| 旧作(規約前)のページ側都合(タイトル未統一等) | works.json 側で表示名を持つため作品ファイルは無改変 |

- P2: 0.5日相当
- P3: 小(OGP/favicon)+ストレッチ(動画ホバー)は別判断
